#  Movie Finder App

A simple and interactive movie search application built using JavaScript and the OMDb API.

##  Features
- Search for movies by title
- Display movie posters, titles, and release year
- Click a movie to view full details
- Fetch additional data (plot, actors, genre)
- "Watch Movie" link redirects users to search results
- Responsive UI with clean design

##  Built With
- HTML
- CSS
- JavaScript
- OMDb API

##  How It Works
1. User enters a movie name
2. App fetches movie list using OMDb API (`s=`)
3. Results are displayed dynamically
4. Clicking a movie triggers another API call (`i=`)
5. Full movie details are displayed

##  Note
This app does not provide movie downloads or streaming. It only fetches publicly available movie data.
